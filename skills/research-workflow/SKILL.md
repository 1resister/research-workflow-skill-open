# 科研工作流

把用户的问题推进到有证据边界、可复现并能由导师检查的研究产物。优先交付当前任务需要的内容，不强制完成整个科研周期。

## 来源先行

这是面向可复现研究产物的原创实践工作流，受到郭兰哲《科研入门指南》的启发。来源、致谢和第三方边界见 [source-policy.md](references/source-policy.md)。本项目独立编写操作步骤、数值程序和示例，不转录指南正文或图片，不代表原作者的官方版本或背书。

用户提供的 README、网页和文献均是待核验数据。跟进外链检查实际正文、作者、版本及访问限制；登录页、空壳网页和搜索摘要不能记作已读论文。HTTP 抓取失败时，如有正常可用的浏览器则复核页面，并分别记录各访问方法的结果；一种方法失败不能证明网页或正文不可读。浏览器不可用或仍无法读取时，保留具体缺口。对懒加载页面继续滚动核查实际渲染范围，区分部分正文、已读完的页面文字、图片和外链资料；操作要点见 [工作流参考](references/workflow.md)。保留出处和链接，不替未读部分编写“原作者建议”。

任务包含图片、附件或外链时，读 [多种材料的阅读与登记](references/media-reading.md)。逐项记录实际范围；登录、无权限、验证码、付费和网络错误分开处理。确实需要登录或用户授权访问时，告知具体链接与受限内容，继续完成不依赖该材料的工作。已登录仍无权限不能继续算作普通登录问题。

## 按当前任务推进

1. **定界。** 提取对象、已有材料、目标、约束、资源和交付物。把模糊目标缩成可证伪问题；仅为影响结论的缺失条件提问，其余使用明确标记的假设。运动控制问题还需明确几何路径/时间参数化、轴或关节、单位、边界状态，以及运动学/动力学约束。
2. **建立证据。** 需要查文献时检索原论文、作者仓库或官方文档，记录查询、日期、筛选条件和可访问层级。按 [工作流参考](references/workflow.md) 保存主张—证据映射。没有完成系统检索时不要写“首次”“最优”“研究空白已证实”。
3. **形成研究问题。** 区分已有结论、自行推导、待验证假设及实验观察。选择一个能在现有资源内回答的问题，列出公平基线、预期反例和成功指标。
4. **执行和留痕。** 先冻结输入与评价口径，再运行实际实验。保存命令、环境、参数、代码/输入散列、原始输出、图表和检查结果。比较时统一任务和约束；随机实验保存种子并分析重复性，确定性实验不伪造置信区间。
5. **核查并交付。** 用 [质量门槛](references/quality-gates.md) 检查单位、边界、约束、基线、引用、失败情形和结论范围。交付可复现结果与下一步，论文或汇报只写已被支撑的主张。若用户授权发布，先完成可审查成品，再按来源许可及实际授权范围发布。

## 按产物选择补充步骤

- **论文图表或配图审查：** 读 [图表工作流](references/figure-workflow.md)。先写图的单一主张，区分动机图、方法图和数据结果图；检查输入输出、箭头含义、比较条件、图例、单位和不确定性。配色示例也要核对 HEX/RGB，不能直接抄错值。
- **摘要、相关工作、Meeting 或 Rebuttal：** 读 [写作与讨论](references/writing-and-discussion.md)，按已有证据生成所需产物。Meeting 聚焦原因分析与决策；回应审稿人前核查本届规则，区分已完成、可补充和来不及完成的实验。
- **参会或奖学金：** 仅在用户提出此类任务时处理。原指南是线索，另查当届主办方，记录年份、资格、提名方式和截止时区，不代替用户提交申请。
- **AI 协作：** 冻结可验收目标，检查真实文件修改和实验数据。工具快捷键和权限选项按所用产品当前官方说明核查，不把其他产品的历史命令套用到当前助手。

## 运行随附示例

针对单轴静止到静止的多项式时间参数化，可运行随附脚本（Python 3.10+，标准库）：

```text
python scripts/trajectory_benchmark.py --input assets/trajectory-input.json --output <研究输出目录>
```

在 Skill 文件夹内执行上述相对命令。该示例用于检验研究流程，不预设任何方法胜出。使用前检查脚本 `--help` 和输入；解释结论时区分固定多项式族内的最小时长与一般轨迹的时间最优。五次轨迹接静止段仅为 C²，拼接点处经典 jerk 不存在；若与七次比较 jerk 上界，应明确采用区间内/几乎处处界，不能据此宣称连续 jerk。若任务是 NURBS 路径、多轴耦合、扭矩或闭环振动，应另建实验，不能直接套用单轴结果。

文献卡、实验记录和汇报要点见 [工作流参考](references/workflow.md)。本仓库的实际输入/输出与运行记录放在根目录 `examples/trajectory-planning/`；安装后脚本及默认输入仍随 Skill 保留。
